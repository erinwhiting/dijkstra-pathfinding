# Dijkstra Pathfinding Algorithm (C++)

This project implements Dijkstra’s Algorithm to compute the shortest path on a weighted graph. It includes an adjacency list representation, a priority queue for efficient node selection, and a simple visualization of the algorithm’s progress.

## Features
- Efficient adjacency list graph structure
- Priority queue for selecting minimum-distance nodes
- Step-by-step visualization of pathfinding
- Clean, modular C++ code

## Technologies
- C++
- STL (priority_queue, vector, etc.)
- SFML (optional visualization)

## How to Run
1. Clone the repository
2. Compile using your preferred C++ compiler
3. Run the executable
